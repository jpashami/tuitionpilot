// Why it’s safe

The AI decides what the invoice says. Code decides what gets paid.

Mandate

Rules in code, checked twice

Payee, student, currency, cap, window, autopay — re-checked before signing. The model can’t override them.

Idempotency

One payment per invoice

Order key from the invoice, claimed in the database before paying. Network error means reconcile, never resend.

Paid vs settled

Committed in seconds

GoBTC co-signs, so the coins can’t move elsewhere. That meets the deadline; the chain confirms later.

Rate

Locked, verified, shown

Priced in sats at request and held 30 minutes. The agent checks the amount before it signs.

Claude tool use · GoBTC Pay instant rail (2-of-3 P2WSH) · local signing · Next.js · SQLite audit trail
