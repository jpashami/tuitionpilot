// The problem

Paying tuition across a border fails differently for each of the three people involved.

Parent · pays

The money can’t leave

Nigeria’s central bank stopped supplying foreign exchange for study abroad. Where a wire works, it takes 1–5 days and carries a 2–4% margin.

“I have the money. My bank won’t send it.”
Student · uploads

No way to tell what is real

Invoices arrive by email. “Updated payment details” looks the same as the real thing — one Canadian scam took CAD 125,000 from 23 students. And once a parent sends money, nobody can prove the school was paid.

“Is this invoice real? Did it arrive?”
University · is owed

No visibility, so it holds the student

The bursar sees an unpaid balance and can’t tell whether money is on its way or was never sent. The only lever is a registration hold — applied to a student who has already been admitted.

“Is this one paying, or dropping out?”

// Architecture

The model reads. Code decides.

Claude turns an invoice into fields. Nothing it returns can authorise a payment — the rules are ordinary TypeScript, and they run again immediately before anything is signed.

The signing key stays on the server. A submit that ends in a network error is reconciled against GoBTC, never resubmitted.
